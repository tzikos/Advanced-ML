# Week 9 — Graph Shallow Embedding

Scripts: `shallow_embedding.py` (standalone script) and `week9_exercises.ipynb` (notebook).

Run all commands from the **project root**.

## Run the script

```bash
uv run Week9/shallow_embedding.py
```

The script loads `Week9/data.pt`, trains a shallow node embedding model, and saves link probability predictions to `Week9/link_probability.pt`.

## Run the notebook

```bash
uv run jupyter notebook Week9/week9_exercises.ipynb
```

Or open `week9_exercises.ipynb` directly in VS Code.

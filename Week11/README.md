# Week 11 — Graph Convolution

Scripts: `graph_convolution.py` (standalone script) and `week11_exercises.ipynb` (notebook).

Run all commands from the **project root**.

## Run the script

```bash
uv run Week11/graph_convolution.py
```

The script loads the MUTAG dataset, trains a graph convolution model, and saves test predictions to `Week11/test_predictions.pt`.

## Run the notebook

```bash
uv run jupyter notebook Week11/week11_exercises.ipynb
```

Or open `week11_exercises.ipynb` directly in VS Code.
